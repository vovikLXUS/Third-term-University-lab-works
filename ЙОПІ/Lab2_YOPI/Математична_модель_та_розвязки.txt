ЧАСТИНА I. ПОВНА МАТЕМАТИЧНА МОДЕЛЬ ЛАБОРАТОРНОЇ РОБОТИ
====================================================================================================

Математична основа цієї лабораторної роботи базується на послідовності незалежних випробувань 
(схема Бернуллі), законах розподілу дискретних випадкових величин та асимптотичних граничних теоремах.

----------------------------------------------------------------------------------------------------
1. СХЕМА НЕЗАЛЕЖНИХ ВИПРОБУВАНЬ БЕРНУЛЛІ ТА БІНОМІАЛЬНИЙ РОЗПОДІЛ
----------------------------------------------------------------------------------------------------
1.1. Означення та умови застосовності:
     - Проводиться серія з n випробувань.
     - У кожному випробуванні можливі лише два взаємовиключні наслідки: подія A ("успіх") 
       або подія ¬A ("невдача").
     - Ймовірність появи події A в кожному досліді є сталою величиною і дорівнює:
         P(A) = p, де 0 < p < 1.
     - Ймовірність протилежної події (невдачі):
         q = 1 - p.
     - Результат будь-якого випробування не залежить від результатів інших випробувань (незалежність).

1.2. Формула Бернуллі:
     Ймовірність того, що в n незалежних випробуваннях подія A настане рівно k разів (0 <= k <= n):
         P_n(k) = C_n^k * p^k * q^(n - k)

     де C_n^k — число сполучень (біноміальний коефіцієнт):
         C_n^k = n! / (k! * (n - k)!)

1.3. Числові характеристики біноміального розподілу:
     - Математичне сподівання:
         M[X] = n * p
     - Дисперсія:
         D[X] = n * p * q
     - Середньоквадратичне відхилення (стандартне відхилення):
         sigma = sqrt(D[X]) = sqrt(n * p * q)

1.4. Сфера використання:
     Застосовується безпосередньо, коли кількість випробувань n є відносно невеликою (n <= 20-30),
     що дозволяє безпосередньо розрахувати біноміальні коефіцієнти без виникнення комбінаторного 
     переповнення.


----------------------------------------------------------------------------------------------------
2. НАЙІМОВІРНІШЕ ЧИСЛО УСПІХІВ (МОДА БІНОМІАЛЬНОГО РОЗПОДІЛУ)
----------------------------------------------------------------------------------------------------
2.1. Означення:
     Число успіхів k_0 називається найімовірнішим, якщо ймовірність його настання є не меншою 
     за ймовірність будь-якого іншого числа успіхів у цій серії випробувань:
         P_n(k_0) >= P_n(k_0 - 1)  ТА  P_n(k_0) >= P_n(k_0 + 1)

2.2. Фундаментальна подвійна нерівність:
     Шляхом розгляду відношень сусідніх ймовірностей P_n(k) / P_n(k-1) доведено, що ціле число k_0 
     задовольняє подвійну нерівність:
         n * p - q <= k_0 <= n * p + p

2.3. Властивості та правила визначення k_0:
     - Довжина проміжку дорівнює:
         (n * p + p) - (n * p - q) = p + q = 1
     - Випадок 1: Якщо вираз (n * p + p) не є цілим числом, проміжок містить рівно одне ціле число:
         k_0 = floor(n * p + p)
     - Випадок 2: Якщо вираз (n * p - q) є цілим числом, на краях проміжку знаходяться два 
       цілих числа, які мають однакову максимальну ймовірність:
         k_01 = n * p - q   та   k_02 = n * p + p


----------------------------------------------------------------------------------------------------
3. ТЕОРЕМА ПУАССОНА (ЗАКОН РІДКІСНИХ ПОДІЙ)
----------------------------------------------------------------------------------------------------
3.1. Умови застосовності:
     - Кількість випробувань n є дуже великою (n -> infinity, практично n >= 100 або 1000).
     - Ймовірність настання події p є дуже малою (p -> 0, практично p <= 0.01).
     - Добуток lambda = n * p є помірною сталою величиною (зазвичай lambda <= 10).

3.2. Формула Пуассона:
     Ймовірність настання рівно k успіхів у n випробуваннях апроксимується виразом:
         P_n(k) ≈ (lambda^k * exp(-lambda)) / k!
     де:
         lambda = n * p
         exp(-lambda) = e^(-lambda)
         k! = факторіал числа k

3.3. Числові характеристики розподілу Пуассона:
     - Математичне сподівання:
         M[X] = lambda = n * p
     - Дисперсія:
         D[X] = lambda = n * p
     - Середньоквадратичне відхилення:
         sigma = sqrt(lambda)


----------------------------------------------------------------------------------------------------
4. ЛОКАЛЬНА ТЕОРЕМА МУАВРА-ЛАПЛАСА
----------------------------------------------------------------------------------------------------
4.1. Умови застосовності:
     - Кількість випробувань n є великою (n >> 1).
     - Ймовірність успіху p не є занадто близькою до 0 або 1 (помірні значення p).
     - Дисперсія є достатньо великою:
         n * p * q > 10 (критерій апроксимації нормальним розподілом).

4.2. Формула локальної теореми Муавра-Лапласа:
     Ймовірність появи рівно k успіхів у n випробуваннях:
         P_n(k) ≈ (1 / sqrt(n * p * q)) * phi(x)
     де:
         x = (k - n * p) / sqrt(n * p * q)
         phi(x) — диференціальна функція Лапласа (густина стандартного нормального розподілу):
         phi(x) = (1 / sqrt(2 * pi)) * exp(-x^2 / 2)

4.3. Властивості функції phi(x):
     - Парність: phi(-x) = phi(x).
     - Максимум досягається при x = 0: phi(0) = 1 / sqrt(2 * pi) ≈ 0.398942.
     - Швидке спадання: при |x| > 4 значення phi(x) прямує до нуля (phi(4) ≈ 0.00013), 
       тому при |x| > 4 вважають phi(x) ≈ 0.


----------------------------------------------------------------------------------------------------
5. ІНТЕГРАЛЬНА ТЕОРЕМА МУАВРА-ЛАПЛАСА
----------------------------------------------------------------------------------------------------
5.1. Умови застосовності:
     - Кількість випробувань n велика, p помірне, n * p * q > 10.
     - Потрібно знайти ймовірність того, що число успіхів k потрапить у певний числовий діапазон:
         k_1 <= k <= k_2

5.2. Формула інтегральної теореми:
         P_n(k_1 <= k <= k_2) ≈ Phi_0(x_2) - Phi_0(x_1)
     де границі інтегрування визначаються за формулами:
         x_1 = (k_1 - n * p) / sqrt(n * p * q)
         x_2 = (k_2 - n * p) / sqrt(n * p * q)

5.3. Функція Лапласа Phi_0(x):
     Визначається інтегралом ймовірностей:
         Phi_0(x) = (1 / sqrt(2 * pi)) * integral_0^чx exp(-t^2 / 2) dt
     Зв'язок із стандартною функцією помилок Gauss error function erf(z):
         Phi_0(x) = 0.5 * erf(x / sqrt(2))

5.4. Властивості функції Phi_0(x):
     - Непарність: Phi_0(-x) = -Phi_0(x).
     - Значення в нулі: Phi_0(0) = 0.
     - Асимптотична межа: при x > 5 функція набуває граничного значення:
         Phi_0(x) ≈ 0.5000 (відповідно Phi_0(-x) ≈ -0.5000 при x < -5).
     - Для симетричного інтервалу [n*p - delta; n*p + delta] формулу спрощують до:
         P_n(|k - n*p| <= delta) ≈ 2 * Phi_0(delta / sqrt(n * p * q))

ЗАДАЧА 1
----------------------------------------------------------------------------------------------------
Умова:
Ймовірність знаходження в кожному прибулому потязі вагонів на дане призначення 0,2. 
Визначити ймовірність того, що в трьох із п’яти потягів, які прибувають протягом однієї години, 
будуть вагони на дане призначення.

1. Дано:
   - Кількість випробувань (потягів): n = 5
   - Ймовірність наявності вагонів у потязі (успіх): p = 0.2
   - Ймовірність відсутності таких вагонів (невдача): q = 1 - p = 1 - 0.2 = 0.8
   - Шукана кількість успіхів: k = 3

2. Вибір математичної моделі:
   Потяги прибувають незалежно один від одного. Кількість випробувань n = 5 невелика. 
   Застосовуємо точну формулу Бернуллі для біноміального розподілу.

3. Використані формули:
   - Формула Бернуллі:
       P_n(k) = C_n^k * p^k * q^(n - k)
   - Формула числа комбінацій:
       C_n^k = n! / (k! * (n - k)!)

4. Покроковий розрахунок:
   1) Знаходимо число комбінацій C_5^3:
        C_5^3 = 5! / (3! * (5 - 3)!) = 5! / (3! * 2!) = (5 * 4 * 3!) / (3! * 2 * 1) = 20 / 2 = 10
   2) Знаходимо степені ймовірностей:
        p^3 = (0.2)^3 = 0.008
        q^(5 - 3) = q^2 = (0.8)^2 = 0.64
   3) Підставляємо у формулу Бернуллі:
        P_5(3) = 10 * 0.008 * 0.64 = 10 * 0.00512 = 0.0512

5. Відповідь:
   P_5(3) = 0.0512 (або 5.12%).

ЗАДАЧА 2
----------------------------------------------------------------------------------------------------
Умова:
Знайти ймовірність того, що в п’яти незалежних випробуваннях подія А відбудеться:
а) рівно 4 рази;
б) не менше 4 разів, якщо в кожному випробуванні ймовірність появи події становить 0,8.

1. Дано:
   - Кількість випробувань: n = 5
   - Ймовірність успіху: p = 0.8
   - Ймовірність невдачі: q = 1 - p = 1 - 0.8 = 0.2
   - Випадок а): k = 4
   - Випадок б): k >= 4 (тобто k = 4 або k = 5)

2. Вибір математичної моделі:
   Схема Бернуллі з n = 5, p = 0.8. Події настання різної кількості успіхів є несумісними, 
   тому ймовірність об'єднання обчислюється як сума ймовірностей за теоремою додавання.

3. Використані формули:
   - P_n(k) = C_n^k * p^k * q^(n - k)
   - P(k >= 4) = P_5(4) + P_5(5)

4. Покроковий розрахунок:
   а) Випадок k = 4 (рівно 4 рази):
        C_5^4 = 5! / (4! * 1!) = 5
        p^4 = (0.8)^4 = 0.4096
        q^1 = 0.2
        P_5(4) = C_5^4 * p^4 * q^1 = 5 * 0.4096 * 0.2 = 0.4096

   б) Випадок k >= 4 (не менше 4 разів):
        Знаходимо P_5(5) (рівно 5 разів):
          C_5^5 = 1
          p^5 = (0.8)^5 = 0.32768
          q^0 = 1
          P_5(5) = 1 * 0.32768 * 1 = 0.32768
        Сумарна ймовірність:
          P_5(k >= 4) = P_5(4) + P_5(5) = 0.4096 + 0.32768 = 0.73728

5. Відповідь:
   а) P_5(4) = 0.4096;
   б) P_5(k >= 4) = 0.73728 (≈ 0.7373 або 73.73%).

ЗАДАЧА 3
----------------------------------------------------------------------------------------------------
Умова:
На кондитерській фабриці 20% всіх цукерок складають льодяники. Знайти ймовірність того, що серед 
400 вибраних навмання цукерок буде рівно 80 льодяників.

1. Дано:
   - Кількість випробувань (вибраних цукерок): n = 400
   - Ймовірність того, що цукерка є льодяником: p = 0.2
   - Ймовірність того, що не льодяник: q = 1 - 0.2 = 0.8
   - Шукане число льодяників: k = 80

2. Вибір математичної моделі:
   Кількість випробувань n = 400 є великою.
   Перевіряємо умову застосовності теореми Муавра-Лапласа:
       n * p = 400 * 0.2 = 80
       n * p * q = 400 * 0.2 * 0.8 = 64 > 10
   Умова n * p * q > 10 виконується із значним запасом, тому застосовуємо 
   локальну теорему Муавра-Лапласа.

3. Використані формули:
   - Локальна теорема Муавра-Лапласа:
       P_n(k) ≈ (1 / sqrt(n * p * q)) * phi(x)
   - Формула для аргументу x:
       x = (k - n * p) / sqrt(n * p * q)
   - Функція Гаусса:
       phi(x) = (1 / sqrt(2 * pi)) * exp(-x^2 / 2)

4. Покроковий розрахунок:
   1) Обчислюємо дисперсію та стандартне відхилення:
        n * p = 80
        sigma = sqrt(n * p * q) = sqrt(64) = 8
   2) Обчислюємо значення нормованого аргументу x:
        x = (80 - 80) / 8 = 0 / 8 = 0
   3) Обчислюємо значення функції phi(x) при x = 0:
        phi(0) = 1 / sqrt(2 * pi) ≈ 1 / 2.506628 ≈ 0.398942
   4) Обчислюємо наближене значення ймовірності:
        P_400(80) ≈ phi(0) / 8 = 0.398942 / 8 ≈ 0.049868 ≈ 0.0499

   5) Порівняння з точним біноміальним значенням за формулою Бернуллі:
        P_exact = C_400^80 * (0.2)^80 * (0.8)^320 ≈ 0.049813
        Абсолютна похибка: |0.049868 - 0.049813| = 0.000055 (менше 0.006%).

5. Відповідь:
   P_400(80) ≈ 0.0499 (або 4.99%).

ЗАДАЧА 4
----------------------------------------------------------------------------------------------------
Умова:
На автомобільному заводі у звичному режимі роботи з конвеєра сходить 100000 автомобілів. Ймовірність 
бракованого автомобіля дорівнює 0,0001. Знайти ймовірність того, що з конвеєра зійшло 5 бракованих 
автомобілів.

1. Дано:
   - Загальна кількість автомобілів: n = 100000
   - Ймовірність браку окремого автомобіля: p = 0.0001
   - Число бракованих автомобілів: k = 5

2. Вибір математичної моделі:
   Кількість випробувань n = 100000 надзвичайно велика, ймовірність p = 0.0001 дуже мала (рідкісна подія).
   Обчислюємо параметр інтенсивності:
       lambda = n * p = 100000 * 0.0001 = 10
   Оскільки n >= 100, p <= 0.01 та lambda = 10 <= 10, застосовуємо граничну теорему Пуассона 
   (закон рідкісних подій).

3. Використані формули:
   - Формула Пуассона:
       P_n(k) ≈ (lambda^k * exp(-lambda)) / k!
     де lambda = n * p, k! = 1 * 2 * ... * k.

4. Покроковий розрахунок:
   1) Параметр інтенсивності: lambda = 10
   2) Значення k! для k = 5:
        5! = 1 * 2 * 3 * 4 * 5 = 120
   3) Підстановка у формулу Пуассона:
        P_100000(5) ≈ (10^5 * exp(-10)) / 120 = (100000 / 120) * exp(-10) = (2500 / 3) * exp(-10)
   4) Значення числа exp(-10):
        exp(-10) ≈ 4.539992976 * 10^(-5)
   5) Знаходимо підсумкове значення:
        P ≈ (2500 / 3) * 0.00004539993 = 833.3333 * 0.00004539993 ≈ 0.037833 ≈ 0.0378

   6) Точний біноміальний розрахунок:
        P_exact = C_100000^5 * (0.0001)^5 * (0.9999)^99995 ≈ 0.037829
        Абсолютна похибка формули Пуассона складає лише 0.000004.

5. Відповідь:
   P_100000(5) ≈ 0.0378 (або 3.78%).

ЗАДАЧА 5
----------------------------------------------------------------------------------------------------
Умова:
Ймовірність того, що пара взуття, яка взята навмання з виготовленої партії виявиться вищого ґатунку 
дорівнює 0,4. Чому дорівнює ймовірність того, що серед 600 пар, які поступили на контроль, виявиться 
від 228 до 252 пар взуття вищого ґатунку?

1. Дано:
   - Загальна кількість пар взуття: n = 600
   - Ймовірність вищого ґатунку: p = 0.4
   - Ймовірність іншого ґатунку: q = 1 - 0.4 = 0.6
   - Межі діапазону: k_1 = 228, k_2 = 252

2. Вибір математичної моделі:
   Число випробувань n = 600 є великим, ймовірність p = 0.4 помірна.
   Перевіряємо умову застосовності:
       n * p = 600 * 0.4 = 240
       n * p * q = 600 * 0.4 * 0.6 = 144 > 10
       sigma = sqrt(144) = 12
   Необхідно знайти ймовірність потрапляння випадкової величини в інтервал [k_1; k_2].
   Застосовуємо інтегральну теорему Муавра-Лапласа.

3. Використані формули:
   - Інтегральна теорема Муавра-Лапласа:
       P_n(k_1 <= k <= k_2) ≈ Phi_0(x_2) - Phi_0(x_1)
   - Формули для меж інтегрування:
       x_1 = (k_1 - n * p) / sqrt(n * p * q)
       x_2 = (k_2 - n * p) / sqrt(n * p * q)
   - Властивість непарності функції Лапласа:
       Phi_0(-x) = -Phi_0(x) => Phi_0(x) - Phi_0(-x) = 2 * Phi_0(x)

4. Покроковий розрахунок:
   1) Обчислюємо значення нижньої та верхньої границі x:
        x_1 = (228 - 240) / 12 = -12 / 12 = -1
        x_2 = (252 - 240) / 12 = 12 / 12 = 1
   2) Використовуємо властивість непарності:
        P_600(228 <= k <= 252) ≈ Phi_0(1) - Phi_0(-1) = Phi_0(1) - (-Phi_0(1)) = 2 * Phi_0(1)
   3) Знаходимо табличне значення функції Лапласа:
        Phi_0(1) ≈ 0.341345 (або 0.3413 за чотиризначними таблицями)
   4) Обчислюємо шукану ймовірність:
        P ≈ 2 * 0.341345 = 0.68269 ≈ 0.6827

   (Примітка: точна біноміальна сума sum_{k=228}^{252} P_600(k) дає 0.7024; при використанні поправки 
   на неперервність з межами [227.5; 252.5] отримуємо x = 12.5 / 12 ≈ 1.0417, 2 * Phi_0(1.0417) ≈ 0.7027).

5. Відповідь:
   P_600(228 <= k <= 252) ≈ 0.6827 (або 68.27%).

Банк обслуговує 100 клієнтів, від кожного з яких може надійти вимога на проведення фінансової

   - Нерівність для моди k_0:
       n * p - q <= k_0 <= n * p + p

   - Точна формула Бернуллі:

        n * p = 100 * 0.4 = 40
        Нижня межа: n * p - q = 40 - 0.6 = 39.4
        Верхня межа: n * p + p = 40 + 0.4 = 40.4
   2) Записуємо подвійну нерівність:
        39.4 <= k_0 <= 40.4
        Оскільки число клієнтів k_0 має бути невід'ємним цілим числом, єдиним значенням є:
        k_0 = 40
   3) Обчислюємо параметри нормальної апроксимації:
        Дисперсія: n * p * q = 100 * 0.4 * 0.6 = 24
        Стандартне відхилення: sigma = sqrt(24) ≈ 4.89898
        Аргумент x: x = (40 - 40) / 4.89898 = 0
   4) Значення функції Гаусса:
        phi(0) = 1 / sqrt(2 * pi) ≈ 0.398942
   5) Розрахунок ймовірності:

   6) Точний розрахунок за формулою Бернуллі:

   Найімовірніше число вимог: k_0 = 40;

ЧАСТИНА IV. ПСЕВДОКОДИ ВИКОРИСТАНИХ АЛГОРИТМІВ
====================================================================================================

Нижче наведено формалізовані псевдокоди всіх фундаментальних алгоритмів, використаних у даній 
лабораторній роботі. Псевдокод описує логіку обчислень незалежно від мови програмування 
з чітким визначенням вхідних параметрів (ВХІД), результату (ВИХІД) та покрокової структури.

----------------------------------------------------------------------------------------------------
АЛГОРИТМ 1: Обчислення факторіалу цілого невід'ємного числа (FACTORIAL)
----------------------------------------------------------------------------------------------------
Опис:
  Ітеративне обчислення добутку всіх натуральних чисел від 1 до n включно.
  Часова складність: O(n). Просторова складність: O(1).

ПСЕВДОКОД:
  ФУНКЦІЯ Factorial(n):
      ВХІД:  n — ціле число (n >= 0)
      ВИХІД: n! — факторіал числа n

      ЯКЩО n < 0 ТОДІ:
          ПОВЕРНУТИ ПОМИЛКУ "Факторіал від'ємного числа не визначений"
      КІНЕЦЬ ЯКЩО

      ЯКЩО n == 0 АБО n == 1 ТОДІ:
          ПОВЕРНУТИ 1
      КІНЕЦЬ ЯКЩО

      res = 1
      ДЛЯ i ВІД 2 ДО n ВКЛЮЧНО РОБИТИ:
          res = res * i
      КІНЕЦЬ ДЛЯ

      ПОВЕРНУТИ res
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 2: Обчислення числа комбінацій (сполучень) C(n, k) (COMBINATION)
----------------------------------------------------------------------------------------------------
Опис:
  Обчислює кількість способів вибрати k елементів з n без урахування порядку: C_n^k = n! / (k! * (n - k)!).

ПСЕВДОКОД:
  ФУНКЦІЯ Combination(n, k):
      ВХІД:  n — загальна кількість елементів (ціле >= 0)
             k — кількість обраних елементів (ціле)
      ВИХІД: C_n^k — біноміальний коефіцієнт (ціле)

      ЯКЩО k < 0 АБО k > n ТОДІ:
          ПОВЕРНУТИ 0
      КІНЕЦЬ ЯКЩО

      numerator = Factorial(n)
      denominator = Factorial(k) * Factorial(n - k)

      ПОВЕРНУТИ numerator / denominator   // цілочисельне ділення
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 3: Формула Бернуллі для дискретної ймовірності P_n(k) (BERNOULLI_PMF)
----------------------------------------------------------------------------------------------------
Опис:
  Розраховує ймовірність настання рівно k успіхів у серії з n незалежних випробувань за схемою Бернуллі.

ПСЕВДОКОД:
  ФУНКЦІЯ Bernoulli_PMF(n, k, p):
      ВХІД:  n — кількість випробувань (ціле >= 0)
             k — бажана кількість успіхів (ціле)
             p — ймовірність успіху в одному досліді (дійсне, 0 <= p <= 1)
      ВИХІД: P_n(k) — ймовірність (дійсне число від 0 до 1)

      ЯКЩО k < 0 АБО k > n ТОДІ:
          ПОВЕРНУТИ 0.0
      КІНЕЦЬ ЯКЩО

      q = 1.0 - p                          // ймовірність протилежної події
      comb = Combination(n, k)             // біноміальний коефіцієнт C_n^k
      prob = comb * (p ^ k) * (q ^ (n - k))

      ПОВЕРНУТИ prob
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 4: Формула Пуассона для моделювання рідкісних подій (POISSON_PMF)
----------------------------------------------------------------------------------------------------
Опис:
  Обчислює ймовірність появи k рідкісних подій при середній інтенсивності lambda = n * p: P(k) = (lambda^k * e^(-lambda)) / k!.

ПСЕВДОКОД:
  ФУНКЦІЯ Poisson_PMF(k, lambda):
      ВХІД:  k — кількість подій (ціле >= 0)
             lambda — інтенсивність (дійсне, lambda > 0)
      ВИХІД: P(k) — ймовірність за законом Пуассона

      ЯКЩО k < 0 ТОДІ:
          ПОВЕРНУТИ 0.0
      КІНЕЦЬ ЯКЩО

      numerator = (lambda ^ k) * exp(-lambda)
      denominator = Factorial(k)

      ПОВЕРНУТИ numerator / denominator
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 5: Диференціальна функція Лапласа / густина нормального розподілу (PHI_DENSITY)
----------------------------------------------------------------------------------------------------
Опис:
  Обчислює значення стандартної густини Гаусса: phi(x) = (1 / sqrt(2 * pi)) * exp(-x^2 / 2).

ПСЕВДОКОД:
  ФУНКЦІЯ Phi_Density(x):
      ВХІД:  x — нормоване відхилення (дійсне число)
      ВИХІД: phi(x) — значення густини (дійсне число)

      constant = 1.0 / sqrt(2.0 * PI)      // ≈ 0.39894228
      exponent_part = exp(-0.5 * x * x)

      ПОВЕРНУТИ constant * exponent_part
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 6: Локальна теорема Муавра-Лапласа (LOCAL_MOIVRE_LAPLACE)
----------------------------------------------------------------------------------------------------
Опис:
  Апроксимація біноміальної ймовірності P_n(k) при великому n за допомогою локальної теореми:
  P_n(k) ≈ (1 / sqrt(n * p * q)) * phi((k - n * p) / sqrt(n * p * q)).

ПСЕВДОКОД:
  ФУНКЦІЯ Local_Moivre_Laplace(n, k, p):
      ВХІД:  n — кількість випробувань (ціле велике, n*p*q > 10)
             k — кількість успіхів (ціле)
             p — ймовірність успіху (дійсне, 0 < p < 1)
      ВИХІД: P_n(k) — апроксимована ймовірність

      q = 1.0 - p
      variance = n * p * q
      std_dev = sqrt(variance)             // стандартне відхилення sigma

      x = (k - n * p) / std_dev            // центрування та нормування

      ПОВЕРНУТИ Phi_Density(x) / std_dev
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 7: Інтегральна функція Лапласа Phi_0(x) (LAPLACE_FUNCTION)
----------------------------------------------------------------------------------------------------
Опис:
  Обчислює інтеграл ймовірностей Phi_0(x) = (1 / sqrt(2*pi)) * integral_0^x exp(-t^2 / 2) dt
  через функцію помилок erf: Phi_0(x) = 0.5 * erf(x / sqrt(2)).

ПСЕВДОКОД:
  ФУНКЦІЯ Laplace_Function(x):
      ВХІД:  x — аргумент інтегральної функції Лапласа (дійсне число)
      ВИХІД: Phi_0(x) — значення функції на проміжку (-0.5; +0.5)

      ПОВЕРНУТИ 0.5 * erf(x / sqrt(2.0))
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 8: Інтегральна теорема Муавра-Лапласа (INTEGRAL_MOIVRE_LAPLACE)
----------------------------------------------------------------------------------------------------
Опис:
  Обчислює ймовірність того, що число успіхів потрапить в інтервал [k_1; k_2] у серії з n випробувань:
  P_n(k_1 <= k <= k_2) ≈ Phi_0(x_2) - Phi_0(x_1).

ПСЕВДОКОД:
  ФУНКЦІЯ Integral_Moivre_Laplace(n, k1, k2, p):
      ВХІД:  n — кількість випробувань (ціле)
             k1 — нижня межа інтервалу успіхів (ціле)
             k2 — верхня межа інтервалу успіхів (ціле)
             p — ймовірність успіху (дійсне, 0 < p < 1)
      ВИХІД: P_n(k1 <= k <= k2) — шукана інтегральна ймовірність

      q = 1.0 - p
      std_dev = sqrt(n * p * q)

      x1 = (k1 - n * p) / std_dev          // ліва нормована межа
      x2 = (k2 - n * p) / std_dev          // права нормована межа

      ПОВЕРНУТИ Laplace_Function(x2) - Laplace_Function(x1)
  КІНЕЦЬ ФУНКЦІЇ


----------------------------------------------------------------------------------------------------
АЛГОРИТМ 9: Знаходження найімовірнішого числа успіхів (MOST_PROBABLE_SUCCESSES)
----------------------------------------------------------------------------------------------------
Опис:
  Знаходження цілого числа успіхів k_0 (моди біноміального розподілу) з подвійної нерівності:
  n * p - q <= k_0 <= n * p + p.

ПСЕВДОКОД:
  ФУНКЦІЯ Most_Probable_Successes(n, p):
      ВХІД:  n — кількість випробувань (ціле > 0)
             p — ймовірність успіху (дійсне, 0 < p < 1)
      ВИХІД: k_0 — найімовірніше число успіхів (ціле число)

      q = 1.0 - p
      upper_bound = n * p + p

      // Оскільки довжина проміжку (n*p + p) - (n*p - q) = 1,
      // єдине ціле число при нецілих межах знаходиться як округлення донизу верхньої межі:
      k_0 = floor(upper_bound)

      ПОВЕРНУТИ k_0
  КІНЕЦЬ ФУНКЦІЇ
